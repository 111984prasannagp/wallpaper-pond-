# Contributing

Thanks for helping improve Studio Pond.

## Before making changes
- Keep changes focused and explain the user impact.
- Do not add generated caches, build output, local environment files, or credentials.
- Preserve the existing visual direction unless intentionally updating it.
- Include screenshots for meaningful UI changes.

## Local checks
```bash
npm install
npm run lint
npm run build
```

## Pull request checklist
- [ ] Describe the change and motivation.
- [ ] Include screenshots for visual changes.
- [ ] Confirm no secrets or private credentials are included.
- [ ] Note environment-variable or deployment changes.
- [ ] Test desktop and mobile layouts when relevant.
